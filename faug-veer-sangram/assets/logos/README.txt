TEAM LOGO LIBRARY
-----------------
Put each team's logo here, named after the team:

    team name            file name
    Blaze Rangers   ->   blaze-rangers.png
    Thunder Hawks   ->   thunder-hawks.webp
    Night Owls      ->   night-owls.png

Rules
  * all lowercase; spaces and symbols become a single dash
  * .png, .webp, .jpg, .jpeg or .svg
  * square, transparent background, about 256x256 px, under 200 KB
  * the name must match what is typed in the admin Teams editor (capitals do not matter)

When a team has a name but no logo link, the page picks the logo up from this folder
by itself. A link typed in the Teams editor always wins over a file here.
